Web Module (Java Servlets)

This web module is the server-side Java part of the project. It is built with plain Java Servlets + JDBC + MySQL (no React, no Node.js, no PHP).

The Swing desktop application (LoginFrame, dashboards, quiz timer thread) is the primary GUI of the project. Start it with: 

mvn compile exec:java

Architecture of this web module: 

Servlet  ->  Service  ->  DAO  ->  JDBC  ->  MySQL
